Running your copy

The easy way

Unzip anywhere and double-click index.html. That’s the whole installation procedure.

The tidy way

Serve it locally so URLs behave like production:

  • python -m http.server 8000

Then visit localhost:8000.

Hosting it publicly

Any static host works: GitHub Pages, Netlify, a $4 VPS with nginx, or a Tor hidden service for maximum resilience.
